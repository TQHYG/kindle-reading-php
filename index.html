如何开始？
  1. 使用 GitHub 登录并前往个人中心。
  2. 在 Kindle 上安装 Kykky 插件，扫描二维码绑定设备。
  3. 在 Kindle 插件内启动同步，或手动在此处上传 log 文件夹。
  4. 从此你的每一分钟阅读都将被铭记。
